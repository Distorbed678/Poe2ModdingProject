## 2. Launcher: DONE 2026-10-29
Built as in the approved mockups (`runtime/r15/mockups/launcher.html`, git-ignored): Poe2Launcher
`2f8a9cf` (+ `7705da3` register link at Play, `a886f42` README). Server side for the usage tiles:
Poe2Protocol `81ffbb6` (`poe_net::stats`), Poe2Server `d734fe0` / `5d3070b` (network rates in the
metrics, `GET /local/metrics`). Choices made while building: web port also moves by 10 per server
(8090, 8100); *Remove* on a hosted server's My servers row deletes it (same name check), so no
server is left unlisted; the launcher's settings drop dropped game versions when read.

**Home, "Get ready to play" step 3:** a single "Set up a server" button, aligned like steps 1
and 2. It opens a small chooser: Create on this computer / Browse public / Add by address.

**Servers page**
- Tabs: My servers / Browse public / **Host**. The hosted card above the list and the top-right
  "Add by address" go away. Only one "Add by address" exists: in My servers (the empty state
  and a single button).
- My servers = everything you can play on. Hosted servers appear there with a "Hosted" badge and a
  quick Start. Creating a server adds it to the list by itself, so the "not in your server list"
  hint goes away.
- Host = every server on this computer, plus Create, Start/Stop, Manage and Delete.
- **Many hosted servers:** each has its own folder (data, config, backups, log) and shares the
  downloaded packages. Several can run at once: the launcher picks free login/game/web ports per
  server and warns about clashes. Migrate the single-server layout (`server/`, `host.json`).
- **Delete = really delete:** stops the server, removes its folder and its list entry; the user
  types the server name to enable Delete.

**Manage panel:** tabs Overview / Settings / Program / Backups (the Log tab goes away).
- Overview: Start / Stop / Open web admin (system browser, one-time token, as today), then
  metrics (CPU and RAM of the process with sparklines, uptime, server and game version, ports,
  network in/out and tick time; network and tick may need new server counters in `/admin/metrics`),
  then the server log.
- Settings: one column of titled sections that fold with an arrow (General open by default):
  General (name, start with the launcher, moved from Overview), Network (public host and LAN /
  public IP buttons, ports, port-forwarding box), Access (open registration, remote web API),
  Advanced (cluster id), Danger zone (Delete). Sticky Apply bar while there are changes. Fix the
  spacing (screenshot 7). No admin password fields (see section 3).
- Program: also fix that a stale "autostart failed" error stays in the log and Program tab after
  a matching package was installed. Check that "open registration" shows `host.json`'s value (it
  showed off while the file said true).

**News:** one vertical feed, newest first: type badge, date, title, the first lines; "Read more"
expands in place. Filter chips: All / Project / Server / Launcher / Client hook. The selected
server's MOTD is pinned on top.

**Library:** tabs Game / Mods / Logs. Game is decluttered: a status header (version, folder,
installed badge, Verify) and one primary action. The Steam download form only opens when needed.
Depots and downloader output go in a folded "Details" section. The client hook becomes a slim card.

**Settings:** top tabs (General / Game & Proton / Steam / Mods / Updates & About / Advanced), each
a spaced single column, sticky Save bar. About moves into Settings.

**Sidebar footer:** plain small text "Launcher v0.5.0" (not clickable).

## 4. Client hook: the in-game "Create account" button: DONE 2026-10-29 (not yet clicked in game)
The button opens `https://<official host>/account/create?theme=poe2` with `ShellExecuteW` (found in
the exe: the path is a UTF-16 string, shell32 is imported), so no Ghidra work was needed: the loader
hooks that export (Poe2ClientHook `2376961`, `register_url` in `poe-hook.toml`, written by the
launcher at Play and by `cargo xtask deploy-client`).

The launcher writes the selected server's registration URL into the hook config at Play. The
hook catches the button's URL open (RE: static Ghidra first on `/0.5.5e.hotfix1`; ask the user for
x64dbg if stuck) and opens that URL instead. Without a URL (not started from the launcher) the
button stays as it is.
